# 部署指南 · 课程签到（v2）

> 目标：从零到「手机扫码就能签到」，大约 20 分钟。
> 环境：HBuilderX（App 开发版）+ uniCloud 阿里云服务空间。

---

| 项 | 值 |
|---|---|
| 服务空间 ID | `mp-11c80251-c4a0-4219-9d53-bd141517b104`（阿里云版） |
| 云函数 | `api`（单个函数，action 分发） |

## 1. 打开项目

1. 下载并安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)，选 **App 开发版**（标准版没有 uniCloud 面板）。
2. 菜单「文件 → 打开目录」，选择本仓库的 `v2` 文件夹。
3. 左侧项目管理器应能看到 `uniCloud-aliyun`、`pages`、`manifest.json`。

> 不需要 `npm install`，HBuilderX 项目自带运行时。

---

## 2. 关联云服务空间

1. 右键 `uniCloud-aliyun` 目录 → **关联云服务空间或项目**
2. 选择 `mp-11c80251-c4a0-4219-9d53-bd141517b104`
3. 关联成功后，目录图标会变成云朵样式

如果列表里看不到该空间：确认 HBuilderX 登录的是创建该空间的 DCloud 账号。

---

## 3. 上传数据库 Schema

右键 `uniCloud-aliyun/database` → **上传所有 DB Schema 及扩展校验函数**。

这一步会创建三个集合，并把权限设为「所有用户不可读写」。

> 如果没有这个右键菜单，说明第 2 步没关联成功。

---

## 4. 上传云函数

右键 `uniCloud-aliyun/cloudfunctions/api` → **上传并部署 → 云端安装依赖（不上传 node_modules）**。

必须选「云端安装依赖」，因为 `api` 依赖 `xlsx`（导出 Excel 用）。

**没弹窗怎么办？** 新版 HBuilderX 会记住上次选择，或者直接在后台按默认方式装依赖，弹窗就不再出现。这时用下面任一方式确认：

1. **网页控制台看**：uniCloud 控制台 → 云函数 → `api` → 详情里查看依赖，能看到 `xlsx` 即已安装。
2. **功能验证**：跑起来后用管理员登录 → 记录管理 → 点「导出 Excel」。能下载就是装好了；若提示「云端未安装 xlsx 依赖」，说明确实没装。
3. **强制补装**：uniCloud 控制台 → 云函数 → `api` → 依赖管理 → 上传 `package.json` → 安装依赖。

> `xlsx` 是懒加载的，**没装也不影响签到主流程**，只有导出 Excel 会失败。所以不必卡在这一步，可以先把应用跑起来再回头补。

---

## 5. 建索引（**关键，不能跳过**）

打开 [uniCloud Web 控制台](https://unicloud.dcloud.net.cn) → 选中服务空间 → 云数据库。

对每个集合点「索引管理 → 新建索引」：

| 集合 | 索引名 | 字段（顺序不能错） | 唯一 |
|---|---|---|---|
| `users` | `uk_account` | `account` 升序 | ✅ 勾选 |
| `sign_records` | `uk_user_course_session` | `userId` 升序 → `courseId` 升序 → `sessionDate` 升序 | ✅ **必须勾选** |
| `sign_records` | `idx_course_time` | `courseId` 升序 → `signTime` 降序 | ❌ |
| `sign_records` | `idx_session_date` | `sessionDate` 降序 | ❌ |
| `courses` | `idx_teacher` | `teacherId` 升序 | ❌ |
| `courses` | `idx_weekday` | `weekday` 升序 | ❌ |

> `uk_user_course_session` 是「一人一课一节只能签一次」的**唯一实现载体**。
> 不建它，功能表面正常，但并发下会写入重复记录。这不是可选项。

## 6. 运行到浏览器

菜单「运行 → 运行到浏览器 → Chrome」。

首次打开是登录页。点底部的 **「首次部署？初始化演示数据」**，
会写入 1 位管理员、4 位教师、12 位学生、7 门课程。

> 这一步可以**重复点**。它是按账号逐个判重的：已存在的跳过，缺的补上。
> 所以如果你之前先注册过一个学生账号，再点一次就能把管理员和教师补齐。
> 弹窗会告诉你「新增了几个账号、跳过了几个」。

然后用演示账号登录（登录页有快捷按钮）：

| 角色 | 账号 | 密码 |
|---|---|---|
| 学生 | `20230101001` | `123456` |
| 教师 | `T1001` | `123456` |
| 管理员 | `admin` | `123456` |

学生登录后直接进入签到页；管理员 / 教师进入 Web 管理端。

## 7. 发布到线上（拿到可扫码的网址）

1. 先在 uniCloud 控制台 → **前端网页托管** → 开通（免费额度足够）。
2. HBuilderX 菜单「发行 → 网站-PC Web 或手机 H5」。
3. 弹窗里勾选 **「将编译后的 H5 上传到 uniCloud 前端网页托管」**，选择服务空间，点击「发行」。
4. 完成后控制台会给出访问域名，形如 `https://xxxx.bspapp.com`。
5. 用任意二维码工具把域名生成二维码，手机扫码即可打开。

> **必须用 https 域名**。浏览器定位接口在 http 下会被直接拒绝，
> 本地 `localhost` 是例外，但手机访问局域网 IP（http）一定拿不到定位。

## 8. 手机体验注意

| 事项 | 说明 |
|---|---|
| 定位权限 | 首次签到浏览器会弹出「允许获取位置」，必须点允许 |
| 定位精度 | 室内误差 30~100 米很常见，演示时阈值建议设 100~200 米 |
| 演示定位 | 如果定位失败，签到页会给出「演示定位」按钮，用课程点位附近的坐标走通流程，页面上会明确标注 |
| 微信内打开 | 微信内置浏览器对 `geolocation` 限制较多，建议用系统浏览器扫码 |

## 9. 常见问题

**Q：页面右上角一直显示「离线演示」？**
说明云函数没调通，自动降级了。依次检查：服务空间是否关联、`api` 是否上传成功、
`common/config.js` 里的 spaceId 是否与服务空间一致。

**Q：签到按钮一直是灰的，显示「未开始」？**
不在签到窗口内。窗口是「开课前 10 分钟 ~ 下课后 10 分钟」。
演示数据里「自动控制原理」的时间是按初始化时刻生成的，重新初始化一次即可。

**Q：提示「本节课已签到」？**
同一账号 + 同一课程 + 同一课次日期只能签一次。换一个学生账号，或在管理端删掉该记录。

**Q：导出 Excel 报错？**
`api` 云函数上传时没选「云端安装依赖」，缺少 `xlsx`。重新上传一次。

**Q：管理端打不开 / 一片空白？**
用学生账号登录了。学生只能进签到页；管理员和教师进管理端。

**Q：能编译成 App 吗？**
可以（「发行 → 原生 App-云打包」）。Android 用自签证书即可；
iOS 需要 Apple 开发者账号；鸿蒙需要华为开发者账号与签名。本轮交付以 H5 为主。
