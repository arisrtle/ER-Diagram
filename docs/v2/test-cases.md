# 测试用例 · 课程签到（v2）

> 目标：用最少的时间证明「三表 + 极简签到 + 管理端」这三件事真的成立，
> 而不是"页面能点开"。
>
> 阅读顺序建议：先看 §2 自动化测试（30 秒出结果），再按 §3 冒烟走一遍，
> 最后用 §4–§7 的用例逐条打勾。

---

## 0. 前置条件

- [ ] 已按 `deploy-guide.md` 完成 §1–§6（关联空间、传 schema、传云函数、建索引）
- [ ] 已建 **2 个唯一索引**：`users.uk_account`、`sign_records.uk_user_course_session`
- [ ] 已点过登录页底部「首次部署？初始化演示数据」
- [ ] 浏览器能打开 `http://localhost:5173`

> **如果教师 / 管理员登不上、但学生能登**，先跑一次「初始化演示数据」。
> 早期版本的 `init` 是「表里只要有一条用户就整体跳过」，导致你注册过一个学生之后，
> 管理员和教师账号永远进不来。新版已改为**按账号逐个补齐**：已存在的跳过，
> 缺的补上，不会产生重复。重新点一次即可修复。

> **演示数据的时间是"初始化那一刻"算出来的。**
> 初始化时会把第一门课设成「今天、当前时间 +10 分钟开课」。
> 隔了一天再测，它会变成"明天有这门课"，签到按钮是灰的 —— 这不是 bug。
> 想重新获得"当前课程"，去控制台清空三个集合，再点一次「初始化演示数据」。

## 2. 自动化测试（先跑这个，30 秒）

两套脚本，不需要 HBuilderX，普通终端即可：

```bash
# 云端逻辑集成测试：内存数据库模拟 uniCloud，31 项
node scripts/v2/test-api.js

# 静态检查：Vue 编译、路由、import、action 注册、mock 覆盖，45 项
node scripts/v2/check.js
```

**当前结果（2026-10-25 实测）：**

| 脚本 | 结果 |
|---|---|
| `test-api.js` | 通过 31 项，失败 0 项 |
| `check.js` | 通过 45 项，失败 0 项 |

`test-api.js` 覆盖了手工很难复现的场景，**这部分不用手工测**：

- 时间窗边界：开课前 11 分钟 → 413；开课前 9 分钟 → 放行
- 距离越界：超阈值返回 410，且**不写入数据库**
- 重复签到：第二次返回 411
- 并发双提交：两个请求同时打，最终结果只可能是 `[成功, 411]`，库里只有 1 条
- 教师数据隔离：T1001 看不到 T1002 的课
- 学生越权：学生调管理接口返回 403
- 密码：库里存的不是明文，是 `salt:hash`
- 初始化幂等：连点两次不会产生重复账号

## 4. 学生端用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| S-01 | 正常签到 | 点「演示定位」→ 点「签到」 | 绿色 Toast「签到成功」；按钮变绿「已签到 / 不可重复签到」；倒计时变「已完成签到 / 签到时间 HH:mm:ss」 |
| S-02 | 定位被拒 | 浏览器弹定位授权时点「拒绝」 | 红点提示定位失败，出现「重试」和「演示定位」两个链接 |
| S-03 | 超范围 | 点「重试」用真实定位（你不在兴庆校区） | 橙色提示「当前位置超出范围 · 距点位 x.x km」；点签到弹窗「不在签到范围内」+ 距离 + 允许范围，按钮「重新定位」 |
| S-04 | 查看记录 | 底部「我的签到记录」 | 顶部显示累计签到次数、涉及课程数；列表按日期分组，显示课程名 + 时间 |
| S-05 | 换设备重复 | 换一个浏览器（或隐身窗口）用同一账号登录 | 直接显示「已签到」，倒计时「已完成签到」，定位区提示「本节课已完成签到，无需再次定位」 |
| S-06 | 双开并发 | 两个标签页都停在签到页 → A 页点签到成功 → B 页（旧状态）再点 | B 页 Toast「本节课已签到」，按钮同步变「已签到」 |
| S-07 | 学生越权 | 地址栏直接输 `http://localhost:5173/#/pages/admin/dashboard` | 被踢回签到页，看不到管理界面 |
| S-08 | 退出登录 | 底部「退出登录」→ 确认 | 回到登录页；再访问签到页会被重定向回登录 |
| S-09 | 注册新学生 | 登录页切「注册」→ 填账号/姓名/班级/密码 → 提交 | 注册成功并自动登录；默认角色是学生 |

> S-03 是最容易复现的失败路径：你本人不在兴庆校区，真实定位必然超范围。
> 不用改代码就能看到 410 的完整交互。

## 6. 管理端用例

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| A-01 | 概览数据 | 用 `admin` 登录 | 4 个统计卡有数字；今日课程、最近签到两个面板有内容 |
| A-02 | 新建课程 | 课程信息维护 → 新增 → 填名称/教师/星期/起止时间/点位/经纬度/阈值 → 保存 | 列表出现新课；状态「启用」 |
| A-03 | 参数校验 | 新建时把结束时间填得比开始时间早 | 保存被拒，提示时间不合法 |
| A-04 | 阈值校验 | 半径填 5（小于 10） | 保存被拒，提示范围 10~1000 |
| A-05 | 编辑课程 | 改某门课的签到点位坐标 → 保存 | 列表坐标更新；学生端刷新后距离随之变化 |
| A-06 | 停用课程 | 把一门课状态改成「停用」 | 学生端不再把该课作为"当前课程" |
| A-07 | 排课视图 | 打开「课程安排」 | 7 列周视图，今天那一列高亮；课程块落在对应星期 |
| A-08 | 教师分配 | 「教师分配」→ 某门课换教师 → 保存 | 课程↔教师表更新；新教师登录后能看到这门课 |
| A-09 | 新增教师 | 「教师分配」→ 新增教师 → 填工号/姓名/院系 | 教师列表出现新人，工作量计数 +0 |
| A-10 | 记录筛选 | 签到记录页 → 选课程 + 日期范围 → 查询 | 列表按条件过滤，条数正确 |
| A-11 | 导出 Excel | 点「导出 Excel」 | 下载 xlsx；列含序号/课程/教师/学号/姓名/班级/日期/时间/结果/距离/经纬度 |
| A-12 | 删除记录 | 某条记录点删除 → 确认 | 列表少一条；该学生刷新签到页后可重新签到（唯一索引已释放） |

> A-11 如果报「云端未安装 xlsx 依赖」，说明云函数依赖没装，
> 按 `deploy-guide.md` §4 的「没弹窗怎么办」处理。
> 这一条**不影响其它任何功能**。

## 7. 边界与安全用例

| 编号 | 场景 | 验证方式 | 预期 |
|---|---|---|---|
| B-01 | 未到时间 | 管理员把某课改到今天但时间设在 2 小时后 | 学生端倒计时「距离开课还有 2 小时」，按钮灰色「未开始 / HH:mm 开启」，点了只弹 Toast |
| B-02 | 已过时间 | 把某课改成今天、1 小时前已下课 | 倒计时「本节签到已结束」，按钮「已结束」 |
| B-03 | 今天无课 | 把今天所有课停用 | 课程卡显示「暂无可签到的课程」，按钮「未开课」 |
| B-04 | 唯一索引生效 | 控制台 → `sign_records` → 手动插入一条与已有记录 `userId/courseId/sessionDate` 相同的文档 | 插入被拒（duplicate key） |
| B-05 | 客户端直连数据库 | 控制台看三个集合的权限 | 均为「所有用户不可读写」；前端只能走云函数 |
| B-06 | 密码不落明文 | 控制台看 `users` 任意一条的 `password` | 形如 `a1b2c3d4:9f8e...`，不是 `123456` |
| B-07 | token 过期 | 登录后手动清掉 localStorage 里的 token 再操作 | 返回 401，自动跳回登录页 |

> B-01/B-02/B-03 的服务端判定（413/412）已由 `test-api.js` 覆盖，
> 手工只需确认**界面表现**与上表一致即可。

## 8. 落库验证（控制台看数据）

签到成功后，去 uniCloud 控制台 → 云数据库 → `sign_records`，新记录应包含：

| 字段 | 期望值 |
|---|---|
| `userId` | 对应用户的 `_id` |
| `courseId` | 对应课程的 `_id` |
| `sessionDate` | 今天，`YYYY-MM-DD`（北京时间） |
| `signTime` | 服务器时间戳 |
| `result` | `"success"` |
| `distance` | 实际算出的距离（米），**由服务端计算，前端传的不算数** |
| `latitude` / `longitude` | 提交时的坐标 |
| `deviceId` | 浏览器 UUID，仅审计用 |

再确认 `users` 里没有 `openid` 字段、`courses` 里 `latitude`/`longitude` 是**标量**而不是对象
—— 这两点对应作业里"不绑定微信"和"单点位"的要求。

## 10. 失败排查速查

| 现象 | 最可能的原因 |
|---|---|
| 右上角有「离线演示」角标 | 云函数没部署成功，或未关联空间 |
| 登录报"账号或密码错误" | 没初始化演示数据，或库里是旧数据 |
| 教师/管理员登不上、学生正常 | 账号缺失。重新点「初始化演示数据」补齐（新版按账号逐个补，不会重复） |
| 签到报"暂无可签到的课程" | 演示数据不是今天初始化的（时间已过期） |
| 签到报 410 但你在点位旁 | 课程坐标或半径配错；或用了 GCJ-02 与 WGS-84 混算 |
| 学生端一直显示"定位失败" | H5 请求 `gcj02` 但未配置地图 key，uni-app 直接报 `map provider not configured`。已在代码中改为 **H5 用 wgs84**；改完需强刷页面。临时可用「演示定位」继续 |
| 能重复签到 | `uk_user_course_session` 索引没建或没勾"唯一" |
| 导出 Excel 报缺依赖 | 云函数未安装 `xlsx`，见 `deploy-guide.md` §4 |
| 页面白屏 | 打开 F12 看 Console 第一条红字；常见是 import 缺失 |
