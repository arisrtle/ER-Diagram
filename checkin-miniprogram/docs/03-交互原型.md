# 03 · 交互原型

**可点击原型：** 用浏览器打开 [`prototype/index.html`](prototype/index.html)（单文件，离线也能打开）。左边的手机可以直接操作；签到页右侧的「模拟定位」滑块可以改变与签到点的距离，看按钮从灰色变成黄色。

下面是全部 19 个界面和它们之间的跳转条件。实线是主要路径，虚线是返回、分支或底部切换。

![界面流转图](prototype/flow.png)

## 页面结构与跳转逻辑

```mermaid
flowchart LR
    home["首页<br/>选择身份"]

    subgraph 学生端
      sLogin["学生登录<br/>学号 + 姓名"]
      sCheck["签到页"]
      sOut["不在范围内"]
      sIn["在范围内"]
      sHold["按住签到"]
      sDone["已签到"]
      sUsed["本机已签过此课"]
    end

    subgraph 管理端
      aLogin["管理员登录<br/>微信授权"]
      aApply["申请成为管理员"]
      aPending["等待审核"]
      aCourses["课程列表"]
      aEdit["新增 / 编辑课程<br/>地图选点、距离阈值"]
      aAdmins["管理员与审核"]
      aStudents["学生管理"]
      aImport["导入结果"]
      aRecords["签到记录"]
      aRecEdit["修改 / 删除记录"]
      aRecAdd["补录"]
      aExport["导出 Excel"]
    end

    home -- 我是学生 --> sLogin
    home -. 本机已登录 .-> sCheck
    sLogin -- 名单匹配成功 --> sCheck
    sLogin -- 不匹配 --> sLogin
    sCheck --> sOut & sIn
    sCheck -. 这台手机已给他人签过 .-> sUsed
    sOut -- 走进范围 --> sIn
    sIn -- 按住 --> sHold
    sHold -- 中途松手 --> sIn
    sHold -- 按满约 1 秒，云函数校验通过 --> sDone
    sHold -- 云函数判定超出范围 --> sOut

    home -- 我是管理员 --> aLogin
    aLogin -- 已是管理员 / 系统首个登录 --> aCourses
    aLogin -- 未授权 --> aApply --> aPending
    aPending -. 被通过后刷新 .-> aCourses
    aCourses -. 底部切换 .- aStudents
    aStudents -. 底部切换 .- aRecords
    aCourses -- 新增 / 点课程 --> aEdit -- 保存 / 删除 --> aCourses
    aCourses -- 点头像 --> aAdmins
    aStudents -- 导入名单 --> aImport
    aRecords -- 点一条记录 --> aRecEdit
    aRecords -- 补录 --> aRecAdd
    aRecords -- 导出 Excel --> aExport
```

| 界面 | 进入方式 | 离开方式 | 关键规则 |
| --- | --- | --- | --- |
| 首页 | 打开小程序 | 我是学生 / 我是管理员 | 本机登录过的学生直接进签到页 |
| 学生登录 | 首页「我是学生」 | 匹配成功 → 签到页 | 学号 + 姓名与名单匹配；无密码、不绑定微信 |
| 签到页 | 登录成功 | 退出 → 首页 | 页面可见时每 5 秒定位一次；超出阈值按钮置灰 |
| 按住签到 | 在范围内按住按钮 | 走满 → 提交；松手 → 取消 | 提交前再定位一次；名单、距离、一机一次全部由云函数判定 |
| 已签到 | 提交成功 | — | 同一课程不能再次提交，不允许重试 |
| 本机已签过此课 | 这台手机已给其他学号签过 | — | 同一课程同一设备 ID 只能签 1 次，无例外 |
| 管理员登录 | 首页「我是管理员」 | 已是管理员 → 课程列表；否则 → 申请 | 云函数从调用上下文取 OPENID，前端无法伪造 |
| 课程列表 | 登录成功 | 底部切换、点课程、点头像 | 每门课程只有一个签到点位 |
| 新增 / 编辑课程 | 新增课程 / 点课程 | 保存、删除、返回 | 地图选点或用当前位置；阈值默认 50 米 |
| 学生管理 | 底部「学生」 | 导入名单 | Excel 需含班级、姓名、学号三列 |
| 签到记录 | 底部「记录」 | 修改、删除、补录、导出 | 删除为软删除，删除后该学生和该设备仍不能自助重签 |
